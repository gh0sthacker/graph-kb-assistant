# Security policy

BB Graph Assistant is alpha software. The local graph explorer is designed to bind to loopback, and MCP tools are intended for local assistant clients. These properties do not replace careful handling of capture data or a review of your local configuration.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version or commit, a concise description, impact, and a minimal reproduction that uses synthetic data. Do not attach raw captures, credentials, tokens, or personal information.

We will acknowledge reports when practical and coordinate a fix before public disclosure. This project does not currently promise a response-time SLA or a supported-version window.
