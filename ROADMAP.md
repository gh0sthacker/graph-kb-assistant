# Roadmap

This roadmap describes intended development, not completed functionality.

- Expand Caido compatibility evidence across versions and supported database layouts; preserve explicit partial status when source snapshots cannot be frozen.
- Complete a reproducible knowledge-base corpus only where source licensing and required notices are verified.
- Improve graph navigation, filtering, and inspection for larger captures.
- Complete the Hermes harness and an evidence-backed hypothesis workflow with human review.
- Add browser and JavaScript coverage to the application-map workflow.

Issues and pull requests can propose changes to this sequence.
